# 📦 Logistics Data Analysis & Optimization

A Python project for analyzing logistics data, visualizing cost drivers, and predicting delivery transit times.

---

## 📁 Repository Structure

- **`Week-1/`** – Baseline data setup and preliminary logistics performance analysis.
- **`Week-2/`** – Data cleaning, feature encoding, and preprocessing pipeline.
- **`Week-3/`** – Advanced data analysis, cost distribution plots, and correlation heatmaps.
- **`Week-4/`** – Machine learning predictive modeling (Random Forest) and optimization strategies.

---

## 📊 Key Highlights

- **Primary Cost Drivers:** Distance and shipment weight are the biggest drivers of transportation cost.
- **Carrier Performance:** Standard Freight is most cost-effective for heavy loads, while Express Shipping Co. carries higher base rates.
- **Predictive Accuracy:** Machine Learning models (Random Forest) forecast delivery transit times with over 88% accuracy ($R^2 > 0.88$).
- **Optimization:** Route re-allocation and dynamic SLA buffering help minimize transit delays.
